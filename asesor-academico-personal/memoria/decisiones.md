# Bitácora de decisiones, razonamientos y vivencias

Aquí se calibra el gemelo. Cada entrada registra algo que Francisco dijo o hizo, con la
menor interpretación posible, y el principio de decisión que revela. Cuando una entrada
confirma o corrige una hipótesis de `perfil/identidad.md`, se actualiza ese archivo y se
anota aquí la referencia.

Formato:
```
## AAAA-MM-DD · Tipo (decisión / vivencia / preferencia / corrección / respuesta de calibración)
- Contexto:
- Lo que dijo o hizo (cita o paráfrasis fiel):
- Principio que revela:
- Impacto en el perfil: (archivo y sección actualizados, o "ninguno")
```

## 2026-09-07 · Decisión de diseño del gemelo
- Contexto: creación del asesor académico personal.
- Lo que dijo: quiere un asesor que lo replique en "pensamientos, decisiones, razonamiento,
  ideas, estrategias, visión, forma"; que se alimente con su experiencia, CV, vivencias,
  estudios y certificados; que vincule material académico nuevo a sus objetivos de
  formación; que le enseñe lo nuevo y le recuerde el conocimiento técnico que se olvida;
  que funcione como suite académica para aprender y prepararse. Se define como gestor
  senior HSEQ e I+D+i con responsabilidad corporativa.
- Principio que revela: sistematizar el propio desarrollo igual que sistematiza un sistema
  de gestión; valora la memoria organizada, el refuerzo disciplinado y la aplicación al
  objetivo.
- Impacto en el perfil: base de `perfil/identidad.md` (principio 6, "aprender es parte del
  trabajo").

## 2026-09-07 · Corrección
- Contexto: el asesor se estaba construyendo dentro del repositorio de la app de torneos.
- Lo que dijo: el repositorio de la app no es adecuado para esto y espera que el gemelo
  entienda la diferencia entre ambos ámbitos.
- Principio que revela: separación clara entre ámbitos (ocio vs desarrollo profesional);
  orden y contexto correcto para cada cosa.
- Impacto en el perfil: el skill se mantiene como paquete independiente, en su propia
  carpeta y listo para su propio repositorio; ninguna mezcla con la app.
